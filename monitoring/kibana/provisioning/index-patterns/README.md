# Kibana Index Patterns Provisioning

Для автоматического создания индекс-паттернов в Kibana 8.x используйте следующий формат.

## Структура файла

Файл `logs-pattern.json` содержит конфигурацию для автоматического создания индекс-паттерна `logs-*`.

## Ручное создание (рекомендуется)

Если автоматическое создание не работает:

1. Откройте Kibana: `http://localhost:5601`
2. Перейдите в **Stack Management** → **Data Views**
3. Нажмите **Create data view**
4. Введите:
   - **Name**: `logs-*`
   - **Time field**: `@timestamp`
5. Нажмите **Create data view**

## Проверка

После создания индекс-паттерна:
1. Перейдите в **Discover**
2. Выберите data view: `logs-*`
3. Логи должны отображаться
