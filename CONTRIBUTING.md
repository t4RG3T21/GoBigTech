# Contributing to GoBigTech

Спасибо за интерес к проекту! Этот документ содержит руководство по внесению изменений в проект.

## Настройка окружения

1. Клонируйте репозиторий:
```bash
git clone https://github.com/t4RG3T21/GoBigTech.git
cd GoBigTech
```

2. Убедитесь, что у вас установлены:
   - Go 1.25.1 или выше
   - Docker и Docker Compose
   - protoc (или используйте Docker для генерации)

3. Запустите зависимости:
```bash
docker-compose up -d
```

4. Сгенерируйте proto файлы (см. README.md)

## Процесс разработки

1. Создайте ветку для ваших изменений:
```bash
git checkout -b feature/your-feature-name
```

2. Внесите изменения и убедитесь, что:
   - Код компилируется без ошибок
   - Тесты проходят
   - Покрытие кода не ниже 40%

3. Зафиксируйте изменения:
```bash
git add .
git commit -m "Описание изменений"
```

4. Отправьте изменения:
```bash
git push origin feature/your-feature-name
```

5. Создайте Pull Request

## Стандарты кода

- Следуйте стандартам Go: `gofmt`, `golint`
- Покрытие кода должно быть не менее 40%
- Добавляйте тесты для нового функционала
- Документируйте публичные функции и методы

## Тестирование

Перед отправкой PR убедитесь, что:
- Все тесты проходят: `go test ./...`
- Нет ошибок линтера
- Код компилируется для всех сервисов

## Безопасность

⚠️ **ВАЖНО**: Не коммитьте секреты, пароли или API ключи в репозиторий!

- Используйте переменные окружения для конфиденциальных данных
- Значения по умолчанию в коде должны быть только для разработки
- В production всегда используйте переменные окружения

## Вопросы?

Если у вас есть вопросы, создайте Issue в репозитории.
